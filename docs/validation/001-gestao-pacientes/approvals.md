# Registro de escopo — MVP de demonstração

Em 2026-10-24, o usuário esclareceu que o projeto será apresentado a um conhecido, provavelmente no Oracle Free Tier, com dezenas de pacientes fictícios e poucos testes essenciais. Na escolha de escopo, respondeu: **“Manter as oito histórias funcionais, com uma implantação pequena e poucos testes essenciais.”**

Esta decisão substitui a proposta anterior de aprovações por papel, base de 10.000 pacientes, cobertura percentual, homologação separada e testes extensos. Não há aprovação adicional pendente para implementar o MVP.

Mantidos: Java, Spring Boot, Thymeleaf, as oito histórias e suas regras de negócio, permissões, restrição de arquivos clínicos, auditoria e um commit por tarefa concluída. A hospedagem será preparada e documentada; criação de recursos em conta Oracle não foi realizada.
